# Contribuir

1. Crie um fork e uma branch.
2. Siga a instalação local. Use um banco vazio e dados inventados.
3. Preserve planejamento separado de realizado, idempotência e isolamento familiar.
4. Em mudanças financeiras/permissões, teste falhas, concorrência e acesso de outra família.
5. Execute `npm run security:check` e `npm run check:public`; revise o diff e os arquivos adicionados.
6. Abra um PR com problema, comportamento final e validação. Não inclua screenshots com dados reais.

Não adicione nomes de pessoas, empresas pagadoras, IDs reais de conexões ou calendários pessoais como regras globais. Regras particulares pertencem à configuração privada da família. Use `example.invalid`, instituições fictícias e identificadores inventados nos exemplos.

Para vulnerabilidades, siga [SECURITY.md](SECURITY.md). Contribuições usam a licença MIT do projeto. Este repositório não contém dados ou credenciais da instalação do mantenedor.
